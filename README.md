---

## ⚡ Fő képességek (Key Features)

- **3D Voice AI Munkatárs**: Valós idejű WebGL 3D robot beszédszinkronnal, aktív hallgatással és közbeszólás-kezeléssel.
- **ZentrionFlow Vizuális Szerkesztő**: Drag & drop folyamattervező valós idejű felvillanó kábelekkel és telemetriával.
- **Interaktív 3D Telemetria Kártya**: Egérkövető 3D dőlés (specular sheen) és élő 4 fázisú folyamatszimuláció.
- **7 Vállalati Rendszermegoldás**: Bejövő email triage, kétirányú CRM (MiniCRM, HubSpot, Salesforce) és számlázás (Számlázz.hu, Billingo).
- **Ingyenes AI Folyamat-Audit**: 4 lépéses ROI kalkulátor és azonnali vezetői kivonat.
- **Intelligens Időpontfoglaló**: Ütközésmentes naptárkezelés, automatikus visszaigazoló emailek és SMS-ek.
- **Monokróm Luxus Arculat**: Pure stark black & white design (`#000000`, white, obsidian grays).

---

## 🛠️ Technológiai stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, React 18, TypeScript)
- **Styling**: Tailwind CSS & Vanilla CSS 3D Keyframe Animations
- **3D Graphics**: Three.js & WebGL 3D Avatar
- **Database / Backend**: Supabase & Next.js API Route Handlers
- **Email Notifications**: Nodemailer (`zentrion-automation.ai@outlook.hu`)
- **Speech Synthesis**: Microsoft Edge Neural TTS (`hu-HU-TamasNeural`, `en-US-ChristopherNeural`)

## 🚀 Helyi futtatás (Local Development)

```bash
# Függőségek telepítése
npm install

# Fejlesztői szerver indítása
npm run dev
```

Nyisd meg a böngészőben: [http://localhost:3000](http://localhost:3000)

## 🌐 Telepítés / Élesítés (Deployment)

A leggyorsabb mód a **Vercel** platform:
1. Importáld ezt a GitHub repository-t a [Vercel](https://vercel.com/) fiókodban.
2. Állítsd be a környezeti változókat a `.env.example` alapján.
3. Kapcsold hozzá az egyedi domainedet (`zentriononline.com`) a Vercel Settings -> Domains menüben.
